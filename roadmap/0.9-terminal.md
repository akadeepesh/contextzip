# Release 0.9: the terminal experience

Four complaints to fix: the output is dense and plain, there is no way to pick files in the terminal, help is a wall of text with nothing to discover commands by, and startup could be quicker. Do release 0.8 first: the summary and the picker both show token counts.

Read [README.md](README.md) first: every chat starts with its ground rules.

Decisions already made, which the prompts enforce:

- The picker lives in the terminal. The browser config UI stays for the AI, workspace and advanced settings.
- Rule priority is fixed and tested in `tests/test_priority.py`: the command, then the project config, then `.gitignore`, then the built-in rules. Nothing in this release may change it.
- `contextzip watch` is frozen. No step touches it.
- No startup-time target. Faster is better; nothing is traded for it.

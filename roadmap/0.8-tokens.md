# Release 0.8: real token counts

Today `contextzip/tokens.py` divides bytes by 4. After this release contextzip counts tokens with a real tokenizer, shows where they are, says whether the ZIP fits, and can enforce a budget.

Read [README.md](README.md) first: every chat starts with its ground rules.

Facts that were checked on 2026-11-10 and that the prompts rely on:

- `tiktoken` 0.14 supports Python 3.9+ and depends on `regex` and `requests`.
- With the environment variable `TIKTOKEN_CACHE_DIR` set, `tiktoken.get_encoding("o200k_base")` reads its vocabulary from a file in that folder named `fb374d419588a4632f3f557e76b4b70aebbca790` (3.6 MB) and makes no network request. Loading takes about 0.2 s; counting runs at about 25 MB/s.
- On this repo's own `cli.py`, o200k gives 4.5 bytes per token, so today's estimate is about 12% high.
